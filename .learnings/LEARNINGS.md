## correction - README audience for public app repos

Public README for Dimas app projects should promote the APK/product first, not expose personal local build paths like `/mnt/c/Users/dimas/...` or WSL-specific commands unless explicitly asked for developer docs. Keep personal machine setup out of promotional README.
